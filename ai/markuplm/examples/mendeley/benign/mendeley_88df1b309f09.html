Fehler 403: Ihr Zugriff auf diese Seite wurde verweigert

Mögliche Ursachen für diesen Fehler sind:

  • Es wurde keine Index-Seite (z.B. index.html oder index.php) hinterlegt
  • Ihre Anfrage wurde von unserer Web Application Firewall unterbunden. Sofern Sie der Betreiber dieser Website sind, können Sie die Web Application Firewall in unserem Control Panel web36.servicehoster.ch:8443 anpassen oder deaktivieren.


Error 403: your request was denied

Possible causes for this error are:

  • No index page (e.g. index.php or index.html) was found
  • Your request was denied by our web application firewall. In case you are the operator of this website, you are able customize or disable the Web Application Firewall in our control panel web36.servicehoster.ch:8443 .
