Yaplex: software development company

Yaplex is a Software Development Company based in Mississauga, Ontario. Yaplex was founded in December 2013 by Alex Shapovalov , who provides his custom software development services in Mississauga, Peel Region, Toronto, and GTA.

We specialize in software development on top of the Microsoft .NET platform and Microsoft Azure cloud services. Our Web Development services include both custom development using ASP.NET MVC / ASP.NET Core frameworks, as well as website development using Umbraco CMS .

Our mobile development services include building apps for Android and iPhone using the Microsoft Xamarin platform .
